# Jeu d'Échecs en Java

Ce projet implémente un jeu d'échecs en Java, conçu pour être exécuté depuis un terminal, sans IDE (Eclipse, IntelliJ, etc.).

## Prérequis

- Java (JDK) installé sur votre système.
- Un terminal pour exécuter les commandes.

## Lancer le programme

1. Ouvrez un terminal et placez-vous dans le dossier `src` du projet :
```bash
cd chemin/vers/le/dossier/src
```

2. Compilez les fichiers du modèle :
```bash
javac model/*.java
```

3. Compilez les fichiers de l'application :
```bash
javac app/*.java
```

4. Lancez le programme :
```bash
java app.Main
```

Bonne partie à vous !
