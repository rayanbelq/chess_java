# Jeu d'échec en Java

  Pour lancer le programme nous vous invitons à ouvrir un terminal, puis vous placer
dans le dossier src, puis exécuter les commandes suivantes :

javac model/*.java
javac app/*.java
java app.Main

  Le programme est conçu pour être exécuté depuis un terminal, sans passer par un
environnement de développement intégré (IDE) comme Eclipse ou IntelliJ.

  Assurez-vous d’avoir Java (JDK) installé sur votre système.
